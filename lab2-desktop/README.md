# Лабораторная №2

Из корня репозитория выполните:

```text
docker compose build lab2 test-lab2
docker compose run --rm lab2 python -m ui_tickets.samples /data
docker compose run --rm test-lab2
docker compose up -d lab2
```

Откройте http://localhost:6082/vnc.html?autoconnect=true&resize=scale в браузере. Это настольное приложение Tkinter в виртуальном рабочем столе. Локальный порт доступен только с вашего компьютера.

Демонстрационные данные вымышлены. Команда samples никогда не перезаписывает существующие источники. Можно заменить файлы в data/lab2 на свои students.xlsx и tickets.docx, затем нажать «Перечитать входные файлы». При отсутствии файлов приложение покажет сообщение; скрытого автоматического создания нет.

В Excel каждый лист — группа, A — фамилия, B — имя, данные со второй строки. В Word: «Билет N», далее минимум три вопроса, с буквальной или штатной Word-нумерацией. Некорректные билеты пропускаются, ошибки записываются в data/lab2/application.log. Сохраняются исходные номера корректных билетов.

После назначения результат немедленно добавляется в data/lab2/results.xlsx. Повторный выбор возвращает самый первый билет студента и добавляет новую строку «Повтор = да». ESC закрывает только окно результата.

Остановка: `docker compose stop lab2`. Удаление контейнеров: `docker compose down`. Данные остаются в подключённых папках. Запускайте один экземпляр приложения на один журнал. Проверка с настоящим Microsoft Excel на Windows выполняется отдельно.

Согласованное отличие от методички: приложение и тесты подготовлены Codex, без использования Copilot.
