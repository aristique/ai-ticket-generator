# Использование ИИ

Подготовка инфраструктуры, исходных английских ТЗ и предварительная реализация №1 с 16 проверками выполнены в Codex. Это не является подтверждением выполнения этапов GitHub Copilot Chat.

Методичка предусматривает Copilot Chat, inline/chat и `/tests`. 28 октября 2026 года пользователь явно выбрал выполнение всех работ здесь через Codex с честным указанием отличий. Copilot и Antigravity не используются; это согласованное отклонение от учебного процесса, а не утверждение о полном соответствии ему.

| Этап | Инструмент | Статус |
| --- | --- | --- |
| Предварительная реализация №1, Docker и 16 проверок | Codex | Проверено в Linux-контейнере |
| Разработка и тесты №1 | Codex | Проверено в Linux |
| Разработка и тесты №2 | Codex | 17 тестов, включая GUI; noVNC проверен в браузере |
| Спецификации №3 | Codex | В отдельном репозитории, до реализации |
| Реализация №3 | Codex | После спецификаций |

Записываем фактически использованную модель, действия и найденные ошибки после реальных сессий. Не публикуем токены, пароли, личные данные студентов или историю авторизации.
