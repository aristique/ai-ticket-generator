# Использование ИИ

Подготовка инфраструктуры, исходных английских ТЗ и предварительная реализация №1 с 16 проверками выполнены в Codex. Это не является подтверждением выполнения этапов GitHub Copilot Chat.

Методичка предусматривает передачу английского ТЗ в Copilot Chat, разработку с inline/chat и подготовку тестов через `/tests`. Пользователь подтвердил доступ к Copilot. Для полного соответствия эти действия нужно действительно выполнить и проверить; до этого этап не отмечается завершённым.

| Этап | Инструмент | Статус |
| --- | --- | --- |
| Предварительная реализация №1, Docker и 16 проверок | Codex | Проверено в Linux-контейнере |
| Разработка и тесты №1 в Copilot Chat | VS Code + Copilot | Требуется сессия Copilot |
| Разработка и тесты №2 в Copilot Chat | VS Code + Copilot | Ожидает этапа №2 |
| Spec Kit для №3 | VS Code + Copilot | В отдельном репозитории, до реализации |
| Реализация №3 | Antigravity | Требуется настройка аккаунта и приложения |

Записываем фактически использованную модель, действия и найденные ошибки после реальных сессий. Не публикуем токены, пароли, личные данные студентов или историю авторизации.
