# Порядок выполнения

1. Подготовить изолированное окружение Docker, инструкции Linux и Windows.
2. Лабораторная №1: ввод с ESC, валидация, выдача билета 1–20, немедленное сохранение Excel, восстановление после ошибок записи, автоматические проверки и проверка в реальном терминале.
3. Лабораторная №2: чтение групп и студентов из Excel, разбор билетов Word, интерфейс Tkinter, повторное назначение первого билета, журнал истории, noVNC, unit-тесты.
4. Проверить обе работы на Windows-ноутбуке: Windows 11, AMD, 32 ГБ RAM, Docker Desktop.
5. Лабораторная №3 выполняется в новом репозитории. Сначала Spec Kit в Copilot, затем отдельный коммит спецификаций и только после него реализация в Antigravity. Требуются ветки спецификаций, реализации и тестов, PR и REPORT.md.
6. Лабораторная №4 выполняется в новом репозитории на Kotlin, без копирования или перевода кода №3. Конвертер, экраны 7/30 дней, графики и статистика, постоянный кэш, unit-тесты, APK и живая демонстрация Android.

Тема №3 по умолчанию — конвертер валют. Дополнение NASA в методичке неоднозначно; до изменения темы нужно уточнение преподавателя.

На 28 октября 2026 года пользователь подтвердил наличие Copilot; Antigravity пока не настроен. Доступность IDE, моделей, фактические результаты и ручные исправления фиксируются по мере выполнения, без выдуманных записей.
