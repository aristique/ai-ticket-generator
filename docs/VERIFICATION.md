# Проверка лабораторной №1

Проверено 28 октября 2026 года в Linux-контейнере linux/amd64.

Команда: `docker compose run --rm test-lab1`.

Результат: **16 passed**. Проверки включают:

- создание Excel-журнала и сохранение каждого студента;
- повторный запуск с дописыванием, без изменения первых трёх строк;
- пустые поля, пробелы, кириллицу и текст, начинающийся с `=`;
- ошибку записи, сохранность предыдущего файла и повтор того же билета;
- файл блокировки Excel;
- защиту от перезаписи повреждённого журнала;
- ESC без Enter, включая незавершённое имя;
- запуск настоящего процесса в псевдотерминале;
- принудительное завершение настоящего процесса после сохранения.

Образ приложения собран и имеет платформу linux/amd64. Автоматические проверки также запускаются в GitHub Actions.

Осталось для полной приёмки:

- Copilot не используется по явному решению пользователя; отличие от методички задокументировано;
- интерактивная проверка на Windows-ноутбуке;
- проверка блокировки реальным Microsoft Excel через Docker Desktop;
- проверка Backspace и поведения клавиатуры в Windows Terminal.

До этих проверок лабораторная не объявляется полностью принятой.
