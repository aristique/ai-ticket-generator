# Подключение Copilot

В рабочей папке проекта подготовлена отдельная официальная переносимая копия VS Code 1.143.1. Подлинность архива проверена по SHA-256 из сервиса обновлений Microsoft. Copilot Chat 0.71.0 уже встроен в эту версию. Системный Code OSS не изменялся.

Для локального запуска на CachyOS используйте подготовленный рядом с репозиторием файл `open-copilot.sh`. Это локальный запускатель, а не часть инструкции переноса на Windows. На Windows используйте собственный VS Code.

1. В официальном VS Code открыть проект.
2. В меню аккаунта войти в GitHub с аккаунтом, у которого есть Copilot.
3. Открыть Chat и убедиться, что модель доступна и отвечает.
4. Передать в чат английское ТЗ из `lab1-console/prompts/implementation.en.md`.
5. Сообщить, что текущая версия подготовлена Codex: попросить проверить требования и выполнить реальные необходимые исправления, затем воспользоваться `/tests` для дополнительных содержательных проверок.
6. Сохранить фактически использованную модель, результат и внесённые изменения в журнале работы с ИИ. Простая проверка готового кода не должна описываться как генерация всей программы в Copilot.

Для лабораторной №2 передадим полное ТЗ до начала реализации её приложения в Copilot.

Для №3 потребуется отдельно настроить Google Antigravity. Спецификации №3 сначала создаются Spec Kit в Copilot; реализация в Antigravity начинается после отдельного коммита спецификаций.
