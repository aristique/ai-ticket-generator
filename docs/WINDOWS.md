# Проверка на Windows 11

Подтверждённая конфигурация: AMD, 32 ГБ RAM, Docker Desktop установлен. Сам запуск на ноутбуке ещё не проверен.

1. Запустить Docker Desktop в режиме Linux containers с WSL 2.
2. Скачать репозиторий в обычную пользовательскую папку, открыть PowerShell в ней.
3. Проверить `docker version` и `docker compose version`.
4. Собрать и запустить №1 по корневому README.
5. Ввести трёх студентов, выйти по ESC, проверить журнал.
6. Запустить повторно, ввести ещё двух: первые три строки не должны измениться.
7. Проверить кириллицу, пробелы, пустые поля, Backspace и ESC в обоих полях.
8. Принудительно завершить контейнер после подтверждённого сохранения: запись должна остаться.
9. Открыть журнал в Microsoft Excel и проверить сообщение о блокировке и повтор сохранения после закрытия Excel. Межсистемные файловые блокировки требуют проверки именно здесь.
10. Запустить №2, проверить рабочий стол в браузере и все сценарии лабораторной.

Перед защитой образы должны быть загружены заранее. Экспорт образов не включает Excel-журналы и другие подключённые данные: папку `data` переносим отдельно. Для №3 отдельно сохраняем настоящий кэш курсов для офлайн-демонстрации. Для №4 заранее устанавливаем APK на Android-устройство или эмулятор.
