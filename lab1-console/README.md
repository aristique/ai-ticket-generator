# Лабораторная №1

Из корня репозитория:

```text
docker compose build lab1 test-lab1
docker compose run --rm test-lab1
docker compose run --rm lab1
```

Введите фамилию и имя, подтверждая Enter. Пустое поле повторно запрашивается. Backspace исправляет ввод; ESC завершает приложение из любого поля. После успешной записи выводится номер билета от 1 до 20 и сообщение о сохранении.

Журнал находится в `data/lab1/journal.xlsx`. Дата и время включают смещение часового пояса контейнера (по умолчанию UTC). После перезапуска данные дописываются. При ошибке сохранения закройте Excel и нажмите Enter: повторяется сохранение той же записи с тем же билетом. ESC в этом случае выходит без сохранения текущей записи, о чём приложение предупреждает заранее.

Файл сохраняется сначала во временный файл в той же папке, затем заменяется готовым файлом. При ошибке предыдущий журнал остаётся целым. Одновременная работа нескольких экземпляров с одним журналом не поддерживается — запускайте один экземпляр №1.

На Linux при другом UID/GID задайте `LOCAL_UID` и `LOCAL_GID` в файле `.env`. По умолчанию используются 1000:1000. На Windows дополнительные настройки UID обычно не нужны.

Принудительное завершение проверяем только после сообщения «Запись сохранена»: предыдущие подтверждённые записи должны остаться в Excel.
